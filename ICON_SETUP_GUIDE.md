## In Xcode

### To Use These Icons:
1. Open your TacoScout project in Xcode
2. In the Project Navigator, select `Assets.xcassets`
3. Select the `AppIcon` folder
4. The Inspector panel on the right will show all configured icon slots
5. Verify that icons are showing (they should load automatically)

### Verification Checklist
- [ ] Open Xcode and navigate to Assets.xcassets
- [ ] Click on AppIcon
- [ ] Verify you see icons in the Inspector for:
  - [ ] iPhone 2x (120×120)
  - [ ] iPhone 3x (180×180)
  - [ ] iPad 2x (152×152)

  - [ ] App Store (1024×1024)

1. Build and run the app: `Product > Build` (or ⌘B)
2. Run on simulator: `Product > Run` (or ⌘R)
3. Check home screen to see your app with the new icon
4. The iOS system will automatically apply rounded corners and drop shadow

## Troubleshooting

### Icons not showing in Xcode?
1. Clean Build Folder: `Shift + Cmd + K`
2. Delete Derived Data: `~/Library/Developer/Xcode/DerivedData`
3. Restart Xcode

### Icon looks blurry?
1. Verify the correct size file is being used
2. Ensure Contents.json mappings are correct
3. Rebuild and restart app

### Wrong icon on home screen?
1. Delete app from home screen
2. Clean build folder in Xcode
3. Rebuild and run again
4. Force quit and relaunch
