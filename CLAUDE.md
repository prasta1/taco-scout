# TacoScout

## Project Overview

iOS app for finding nearby taco spots — map view, ratings, directions, favorites.

## Tech Stack

- SwiftUI
- iOS 17.0+
- MapKit, CoreLocation

## Build

```sh
open TacoScout.xcodeproj
```

## Key Features

- Live map with taco place pins
- Filters: distance, rating, price, open-now
- Lucky Pick (random selection)
- Directions: Apple Maps, DoorDash, Uber Eats, Grubhub
- Favorites
- Home screen widget

## Notes

- Uses Apple Maps, not Google Maps
- Location used only while app is open
- Privacy-focused (no data collection)
